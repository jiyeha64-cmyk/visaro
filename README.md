# 비자로 (Visaro)

체류자격을 고르고 몇 가지 질문에 답하면, **법무부 「사증발급 안내매뉴얼」(2026. 11.)** 기준으로 나에게 해당하는 제출서류만 걸러서 보여주는 웹 서비스 시안입니다.

> ⚠️ 이 사이트는 **공식 정부 누리집이 아닙니다.** 학생 프로젝트 시안이며, 정확한 안내는 하이코리아(hikorea.go.kr), 외국인종합안내센터 1345, 관할 재외공관에서 확인하세요.

## 주요 기능
- 매뉴얼 수록 체류자격 37개 (A-1 ~ H-2)
- 상황별 질문 → 해당 서류만 필터링, 서류마다 필요 이유 표시
- 해외 체류기간 계산기 (제3국 범죄경력증명서·아포스티유 필요 여부)
- 한국어 · English · 中文 · 日本語 전환
- 체크리스트, 목록 복사

## 폴더 구조
| 경로 | 내용 |
|---|---|
| `index.html` | 완성된 웹페이지 (이 파일 하나로 동작) |
| `src/template.html` | 화면 디자인·동작 코드 |
| `src/data/01~08.js` | 체류자격별 질문·서류 규칙 데이터 |
| `src/strings.json`, `src/tr.json` | 번역 원문과 영·중·일 번역 |
| `build.py` | `src/` 를 합쳐 `index.html` 을 다시 만드는 스크립트 |

## 데이터 수정 방법
1. `src/data/` 에서 해당 체류자격 파일을 고칩니다.
2. `python build.py` 를 실행하면 `index.html` 이 새로 만들어집니다.
3. 새 문구를 추가했다면 `src/strings.json`·`src/tr.json` 에 번역도 추가해야 다른 언어에서 번역되어 보입니다 (없으면 한국어로 표시).
